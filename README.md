# Mina the Hollower：introSea 地图逆向与复原

这是游戏开场船只场景的可复现研究归档。素材来自本机游戏安装目录解包出的原始地图、图集、调色板和动画资源。复原图由脚本从这些原始资源重建；用户截图只用于定位和像素比对，没有贴进成品图。

## 归档状态

完整快照包含方法文档、Codex skill、重建脚本、示例图、对齐和校验数据、REA 静态证据、解析参考代码与许可证，以及复现所需的最小原始输入。归档 ZIP 和校验文件待提交。

## 快照内容

- 资料/：解码方法、踩坑记录、接手入口、复原图和校验数据。
- 技能/mina-map-decoder/：可复用 skill 与独立重建脚本。
- 工作区脚本/：原始提取、渲染、合成脚本及 REA 证据。
- 原始输入/by-package/：复现 introSea 所需的最小地图、图集、调色板和 ANB 资源子集。
- 解析参考/：参考解析器源码与随附许可证。

## 复现

解压完整快照后，在快照目录运行：

python -X utf8 ./技能/mina-map-decoder/scripts/rebuild_introsea.py --assets ./原始输入/by-package --out ../复现输出

## 证据边界

开启船只区域（排除角色遮挡框）与游戏截图的 RGB 像素一致率为 99.04499%。这是该选定区域的静态像素比对结果，不代表整张截图、完整运行时逻辑或动画时序已经复原。更多边界和计算口径见方法文档及 method_verification.json。
